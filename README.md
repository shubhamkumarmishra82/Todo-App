<p>Todo Management System</p>
A Full Stack Todo Management Application developed using Java, Spring Boot, React.js and MySQL. This application allows users to manage their daily tasks with authentication, task priority, due dates and status tracking.

<p>🚀 Technologies Used</p>
<p>Backend</p>
Java 17
Spring Boot 3.2.5
Spring Security
Spring Data JPA
Hibernate
MySQL
JWT Authentication
BCrypt Password Encryption
Maven

<p>Frontend</p>
React.js
JavaScript
Redux Toolkit
React Router DOM
Bootstrap 5
CSS

<p>✨ Features</p>
User Registration: Users can create a new account.
User Login: Secure login using email and password.
JWT Authentication: Secure authentication using JSON Web Tokens.
Add Todo: Create new tasks with title and description.
View Todos: Display the user's task list.
Update Todo: Edit existing task details.
Delete Todo: Remove tasks.
Task Priority: Manage tasks based on priority.
Due Date: Set deadlines for tasks.

Task Status: Track tasks as Pending or Completed.

User-Specific Tasks: Each user can access only their own tasks.
